# Personal Learning Dashboard (PLD)

## Project Overview
The Personal Learning Dashboard is a responsive, UI-only web application designed to organize learning modules, track progress, and present a professional user profile.

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5

## Features
- UI-only Login page
- Dashboard with Module → Unit → Topic hierarchy
- Learning progress tracker
- Professional user profile with skills and GitHub link
- Responsive image gallery with hover effects
- Fully responsive design (mobile-first)
- Cross-browser compatibility

## Responsive Strategy
- Implemented using Bootstrap’s mobile-first grid system
- Responsive navigation bar with collapse support
- Layout adapts across mobile, tablet, and desktop screens

## Cross-Browser Support
- normalize.css used to reset default browser styles
- Bootstrap ensures consistent UI components
- Tested on Chrome, Firefox, and Edge

## UX Enhancements
- Hover effects on cards and navigation
- Smooth CSS transitions
- Sticky header for better navigation
- Optional dark mode support

## Notes
- This is a UI-focused project
- No backend or authentication logic is implemented
- Static images are used for profile and gallery
